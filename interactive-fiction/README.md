# interactive-fiction · 互动小说配置包（Muse）

**把一段提示词粘进对话框，就开始一部你能走进去的小说。** 你扮演一个人，它扮演世界、导演和所有人。

- 版本：**v0.1.0-beta**（不发布 Release）
- 适配：**Meta Muse**（`muse.ai` 是另一个产品，见下方核查）
- 形态：**纯文本粘贴包**，不依赖任何未经验证的平台接口

---

## 30 秒开始

1. 打开 `muse/START_PROMPT.md`，复制两条 `---` 之间的全部内容。
2. 粘进 Muse 的对话框，发送。
3. 回一句设定（"明代，我是都察院小官"），或者只打"开始"。

不用装东西，不用上传文件，不用记命令。它自己会开场。

## 平台核查（截至 2026-10-29）

按"未验证的接口不得假设存在"，先把话说清楚。

| 能力 | 状态 | 依据 |
|---|---|---|
| Meta Muse 存在，2026-09-08 上线 | **已核实** | 多家报道一致；定位为个人 AI Agent，有云端电脑、跨对话记忆 |
| 长期记忆、可查看/编辑记忆文件 | **已核实（二手报道）** | 扎克伯格访谈转述"用户可以打开自己的记忆文件，读它、改它"，未见官方文档原文 |
| 支持上传文件、连接外部服务 | **已核实（二手报道）** | 产品介绍与第三方评测均提及，Free 档有单次上传数量限制 |
| 单条消息长度上限 | **未核实** | 未见公开数值。本包 START_PROMPT 约 2,600 字，按常规聊天产品可一次粘贴 |
| 是否有"配置/人格导入"官方入口 | **未核实** | 未找到官方文档。**本包不依赖它** |
| 记忆文件路径、格式、容量 | **未核实** | 同上。**本包不依赖它** |
| 附件是否进入长期记忆 | **未核实** | 因此不把设定做成"必须上传的附件" |

**另外两点必须说明**：

1. `muse.ai` 这个域名是**视频托管与检索平台**，和角色扮演无关。你说的应该是 Meta 的 Muse，两者别混。
2. 关于 Meta Muse 的公开报道里，存在两种描述：一种是"能干活的个人 Agent"，一种是"消息应用里的情感陪伴角色"。**我无法确认它们是同一个产品的不同入口，还是两条产品线。** 本包对两者都成立——因为它只依赖"能粘贴文本、能连续对话"。

**结论**：MVP 只用纯文本。文件、记忆、导入、配置——全部是"可选增强"，且都标注未验证。

## 七个文件

| 文件 | 作用 | 什么时候用 |
|---|---|---|
| `muse/START_PROMPT.md` | 初始化提示词，含规则、写法、结尾五型、存档格式 | 开局粘一次 |
| `muse/WORLD.md` | 世界：铁律、地理、势力、秘密分层 + 三套预设 + 填好的例子 | 想自己造世界时 |
| `muse/CHARACTERS.md` | NPC 七项档案、语言指纹四维、四种债、信息边界 | 人物开始混同的时候 |
| `muse/STORY_STATE.md` | 当前场景、时间、在场、未结、已知/未知、已用 | 每 8 轮覆盖一次 |
| `muse/MEMORY_PROMPT.md` | 让它把前情压成 500 字存档的指令 | 每 15–20 轮，或它开始忘事时 |
| `muse/RESTORE_PROMPT.md` | 新会话恢复的指令 | 换对话、隔了几天 |
| `muse/MECHANICS.md` | 七个毛病的治法（说话同质、描写重复、忘关系、场景不动、复述、没方向、结尾套路） | 调的时候看，不用粘给模型 |

## 长局怎么活下来

模型会忘。别指望它记住，指望**文本**。

```
每 8 轮 → 它输出一个【存档】块 → 你覆盖进 STORY_STATE.md
每 15–20 轮 → 发一次 MEMORY_PROMPT 的指令 → 它给你压缩版存档
换会话 → 贴 RESTORE_PROMPT + 存档 + 人物语言指纹
```

**最小方案**（不想管文件）：只留存档块和人物语言指纹，其它都能重建。

## 测试了什么，没测什么

**测了**（详见 [`tests/TEST_RECORD.md`](tests/TEST_RECORD.md)）：

- 35 轮历史权谋 + 15 轮都市生活，AI 模拟玩家，同模型 GM。
- 场景切换 5 处、长期缺席 NPC 两次回归（都带变化）、玩家中途出城（偏离主线）、受伤、收尾。
- 10 项测试点判定：**通过 3、部分 6、失败 1**。失败项是**描写模具化**（雪、两根指头、"看了一眼"反复出现）。

**没测**：

- 没有在真实 Muse 里跑过（缺账号与真实环境）。
- 没有真人玩家。
- 没有验证截断后的恢复（只在本地重建过存档卡）。
- 没测多分支（只跑了一条线）。

**测试后改了四条**（替玩家搬家、期限蒸发、结尾同型、天气连用），**但没重测**。改条款不等于改行为，这条留到 v0.1.1。

## 已知问题

1. **描写会在长局里退化成模具**：雪、手指、"看了一眼"。机制写了，没强制它每轮自填"已用"栏。
2. **未结线索会默默过期**：加了一条"到期必须处理"，未经检验。
3. **平台未知**：Muse 的记忆与导入机制未核实，长局完全依赖用户手动维护存档。
4. **同一模型既写又审**，审计结论的独立性有限。
5. **成人内容边界**：本包设定为"情感与张力为主，不写露骨细节"，并遵守平台规则；**不含任何绕过限制的写法**。实际表现取决于平台策略。
