# interactive-fiction · 互动小说配置包（Muse）

**把一段提示词粘进对话框，就开始一部你能走进去的小说。** 你扮演一个人，它扮演世界、导演和所有人。

- 版本：**v0.1.1-beta**（不发布 Release）
- 适配：**Meta Muse**（网页入口 `muse.ai`）
- 形态：**纯文本粘贴包**，不依赖任何未经验证的平台接口

---

## 30 秒开始

1. 打开 `muse/START_PROMPT.md`，复制两条 `---` 之间的全部内容。
2. 粘进 Muse 的对话框，发送。
3. 回一句设定（"明代，我是都察院小官"），或者只打"开始"。

不用装东西，不用上传文件，不用记命令。它自己会开场。

## 七个文件

| 文件 | 作用 | 什么时候用 |
|---|---|---|
| `muse/START_PROMPT.md` | 初始化提示词，含规则、写法、结尾五型、存档格式 | 开局粘一次 |
| `muse/WORLD.md` | 世界：铁律、地理、势力、秘密分层 + 三套预设 + 填好的例子 | 想自己造世界时 |
| `muse/CHARACTERS.md` | NPC 七项档案、语言指纹四维、四种债、信息边界 | 人物开始混同的时候 |
| `muse/STORY_STATE.md` | 当前场景、时间、在场、未结、已知/未知、已用 | 每 8 轮覆盖一次 |
| `muse/MEMORY_PROMPT.md` | 让它把前情压成 500 字存档的指令 | 每 15–20 轮，或它开始忘事时 |
| `muse/RESTORE_PROMPT.md` | 新会话恢复的指令 | 换对话、隔了几天 |
| `muse/MECHANICS.md` | 七个毛病的治法（说话同质、描写重复、忘关系、场景不动、复述、没方向、结尾套路） | 调的时候看，不用粘给模型 |

## 长局怎么活下来

模型会忘。别指望它记住，指望**文本**。

```
每 8 轮 → 它输出一个【存档】块 → 你覆盖进 STORY_STATE.md
每 15–20 轮 → 发一次 MEMORY_PROMPT 的指令 → 它给你压缩版存档
换会话 → 贴 RESTORE_PROMPT + 存档 + 人物语言指纹
```

**最小方案**（不想管文件）：只留存档块和人物语言指纹，其它都能重建。

## 测试了什么，没测什么

**v0.1.1 做的是最小定向测试，不是文学评分**（详见 [`tests/TEST_RECORD.md`](tests/TEST_RECORD.md)）：

| # | 测什么 | 结果 |
|---|---|---|
| 1 | 15 轮连续，控制权与重复描写 | 通过（1 处灰区） |
| 2 | 跨日期／跨年转场 | 通过（出现"万历元年正月"，0 次"隆庆七年"） |
| 3 | 有期限的承诺到期 | 通过（第 15 天交割，并以漕帮出船为代价） |
| 4 | 物品失去／找回／转交 | 通过（抄本两次转交，原件最终交出） |
| 5 | 保存 → 新会话 → 恢复 | 通过（173 字恢复卡，续写 172 字，5 项检查全过） |

**灰区照记**：第 15 轮玩家只说"我在院门口等"，GM 替他完成了交割动作——没替他想，但替他做了。

**没测**：真实 Muse 环境、真人玩家、长对话截断后的恢复、多分支。

**旧证据保留**：v0.1.0 的 35 轮记录仍以失败样本留在 `tests/records/`，未改写。

## 已知问题

1. **环境词密度仍偏高**：15 轮里"风"6 次、"冰"5 次。装饰性重复基本消失，但没到理想。
2. **控制权仍有灰区**：玩家说"我等"，GM 会替他完成一个他显然会做的动作（交割、接过、起身）。规则禁止"替他决定"，没禁止"替他把事办完"。
3. **平台未知**：Muse 的记忆与导入机制未核实，长局完全依赖用户手动维护存档。
4. **同一模型既写又审**，审计结论的独立性有限。
5. **成人内容边界**：本包设定为"情感与张力为主，不写露骨细节"，并遵守平台规则；**不含任何绕过限制的写法**。实际表现取决于平台策略。
