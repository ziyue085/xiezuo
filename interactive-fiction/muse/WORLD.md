# WORLD · 世界设定

> **怎么用**：复制「空白模板」，填到能开工就停（不必填满）。填完接在 START_PROMPT 后面发，或者直接存成文本，恢复故事时一起贴回去。
> **原则**：写"能影响一句话怎么说"的东西。写不进台词的设定，删掉。

---

## 空白模板

```
【世界】
名称：
时代／技术水位：一句话（有没有电、有没有枪、有没有魔法）
基调：明亮／灰／冷硬　　严酷度：温和／标准／冷硬

【一条铁律】
这个世界什么可能、什么不可能、违反的代价：
（例：魔法存在但昂贵——每次施法要付出记忆、寿命或名字。）

【三句话历史】
1.
2.
3.

【地理】（≤7 处，写"从哪到哪多久"）
- 地点｜能找到什么｜到别处多久｜谁的地盘

【势力】（3–5 个，写要什么、用什么手段）
- 名称｜要什么｜手段｜与谁对立

【主线与支线】
主线（带倒计时）：
支线一：
支线二：

【开局局势】
此刻谁在做什么：

【秘密分层】
核心（最后三分之一才揭）：
中程（十轮内可揭）：
贴身（随时可揭）：
```

## 填好的例子（历史权谋）

```
【世界】
名称：隆庆六年的北京
时代：明代，火器已有，无超自然
基调：冷硬　　严酷度：标准

【一条铁律】
没有奇迹。一句话能杀人，一张纸也能；但要有凭据、有人信、有人怕。

【三句话历史】
1. 十年前夺门之变，旧党尽黜，边镇换将。
2. 先帝在位六年，垂拱不问事，票拟尽出内阁。
3. 今上病重四十天，储位未定，三方都在动。

【地理】
- 都察院｜文书、御史、档案房｜到午门半个时辰｜左都御史陈洪
- 通州码头｜漕帮、脚夫、南货｜到京城一日｜漕帮三爷
- 边镇（宣府）｜兵、马、粮饷｜快马十二日｜总兵王崇
- 司礼监｜批红、密折｜进宫门即到｜掌印太监冯保

【势力】
- 内阁｜要"稳"，怕边事坏了和谈｜拖、压、换人｜与司礼监对立
- 司礼监｜要"信息"，控奏折通道｜扣、改、传话｜与内阁表面合作
- 边将｜要粮饷，怕裁军｜养寇、报捷、拥兵｜与内阁互相利用

【主线与支线】
主线：一份伪诏副本从档案房流出，三日内必须查清是谁放的（倒计时：司礼监来取件）。
支线一：漕帮想借这条线洗一批私货。
支线二：周有德想把女儿送进女学，需要一份人情。

【开局局势】
今早卯时，你到档案房，案上多了一份诏书副本。周有德还没来。楼下有人在扫雪。

【秘密分层】
核心：伪诏是先帝近侍与内阁某位共同拟的，为的是给储位留后手。
中程：周有德私改过一份旧档，把柄在你手里。
贴身：周有德女儿的事，他谁也没说。
```

## 写作提醒

1. **七处地点够了。** 多了记不住，也没人去。
2. **势力写利益，不写善恶。** 三方各有各的理，冲突才立得住。
3. **三个秘密各一条。** 只有核心秘密，前面会闷；只有贴身秘密，故事没骨头。
4. **铁律一旦定下不许改。** 为了方便让玩家脱困而改规则，是这个世界第一次失信。
