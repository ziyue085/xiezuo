# STORY_STATE · 当前状态

> 这是唯一一份**每轮都可能变**的文件。模型在你说 `/存档`（或开启定期存档后每 8 轮）时输出存档块，你把它覆盖到这里。
> 换会话、`/读档`、上下文变长影响质量时，用它接得上。

---

## 模板（和 START_PROMPT 的存档块一致，可直接复制替换）

```
【存档 · 第N轮】
时间：　　　　　　　地点：
在场：姓名（与我的关系·当前态度）／姓名（…）
玩家：身份，伤势
持有：
已失：
未结：①标题｜谁在等｜第几天到期｜触发条件｜超期后果
　　　②…
已结：①标题（第几轮·结果）
已知：我确知的事实（3–6 条）
未知：我还没弄明白什么（2–5 条，**不写答案**）
已用：近三轮用过的动作／天气／比喻（防重复）
下一步压力：一句（新会话从这里接）
```

---

## 填好的例子

```
【存档 · 第 12 轮】
时间：隆庆六年三月十五　地点：都察院 档案房
在场：周有德（上司·怕我）／柳五（杂役·欠我二两）
玩家：都察院七品经历；左臂刀伤，未愈
持有：诏书副本抄本、档案房钥匙副本
已失：原件的火漆封皮（第 9 轮被冯保的人收走）
未结：①伪诏谁放的｜司礼监｜第 15 天｜他们来取件｜副本被收缴
　　　②周有德私改档｜我｜第 20 天｜他用得上我时｜他反咬
已结：①封皮被收走（第 9 轮·冯保的人当面撕了火漆，没留字据）
已知：副本存在；周改过档；冯保也在找这份东西
未知：先帝近侍是谁；内阁谁签的字（不写答案）
已用：铜钥匙／雪／"声儿不对"
下一步压力：楼梯上有人上来，不止一个
```

## 三条使用纪律

1. **只记会变的东西。** 世界规则、地理、势力写在 `WORLD.md`，这里不重复。
2. **"已用"栏必须填。** 它是防重复的唯一手段：写新一轮之前扫一眼，近三轮用过的动作、比喻不再用。
3. **"未结"必须有到期和超期后果。** 没期限的线索会烂在手里——故事跑到三十轮没方向，多半就是这一栏空了。

---

## 什么时候该更新

| 情况 | 改哪一栏 |
|---|---|
| 换了地方／过了时间 | 时间、地点（跨年要连年号一起改） |
| 有人来／走／死 | 在场（死者永久移出） |
| 我学到新东西 | 已知 +1，未知 −1 |
| 欠了人情／结了仇 | 在场栏的态度，或"未结"加一条 |
| 得到／失去／交出东西 | 持有与已失两栏，**同一件不能两边都有** |
| 用了一个动作／比喻 | 已用（滚动保留最近三条） |
| 主线推进了一格 | 未结里改写这条，或结掉 |

**已结的事不能重演。** 结掉就从"未结"删掉，写进"已结"，并且**带上结果**（谁办的、什么代价）。只写进"已知"不够——新会话会把它当成还没办的事再问一遍。

---

## 存档只给玩家看得到的

存档是给你（玩家）看的，不是给导演看的。

- **未知**栏写"我不知道什么"，不写"答案是某某"。
- 幕后已经安排好、但还没揭的事，不进存档。
- 写进去的每一条，都必须是**你在剧情里已经知道或已经怀疑**的。
