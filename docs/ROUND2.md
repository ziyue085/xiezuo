## 2. 这轮真正有价值的四个发现

### 2.1 幽默是稳定失败点（第二轮复现）

R05 三位评审一致判 A 胜，理由高度一致：

> 「甲一路笑到底，甲最后三行把喜剧写成了旧情。」（judgeR1）
> 「甲守住闹剧、让老板自欺到底；乙把误会转成旧情回望，笑点让位给温情。」（judgeR2）
> 「甲一路算计到底，乙半途拐进旧情。」（judgeR3）

结尾对照（两篇都是我们自己的产物）：

> A：赵鹏小声说："姐，我们刚聊到一半。"　"见着了。"我说，"小徐刚才笑了。"
> B：老周的笔停了一下。"放姜吗？"　"不放。"　他在纸上添了三个字：不放姜。

B 的结尾是**一个安静的、有温度的、设计过的瞬间**——正是这套 skill 反复鼓励的写法（动作收尾、留白、不解释）。它在文学短篇里有效，在喜剧里致命。

这和第一轮 S06 是同一个病灶，**在两个独立场景、五个评审判断里复现**。因此可以下一个比第一轮更硬的结论：

> **本 skill 会把喜剧推向温情，这是稳定缺陷，不是偶发。**

v0.1.1 加过一条"笑点之后不要立刻转抒情"，没有挡住。原因大概是：这条规则只管"立刻"，B 是在笑点之后走了一段才拐弯。

v0.1.2 补了一条更前置的判断（`fiction.md` §9）：**喜剧的结束条件是局面收束，不是情感揭示。** 并附一句自查："如果最后一段让人心里一软，先怀疑自己把喜剧换成了温情。"——**这条改动没有重测**，属于待验证假设。

### 2.2 约束遵守仍然接近抛硬币

58%，与第一轮的 57% 几乎一样。**加了"用户要求优先"的优先级条款，没有改变这个数字。**

具体表现：
- R07（润色）：judgeR1 说 B"是改写并且换了文体"，judgeR2 说 B"越界补写离职细节并埋下下一场的钩子"。原任务明确要求"不要扩写、不要加新情节"。
- R01：judgeR1 说 B"在欠费口径上松动"——即数字前后不一致。
- 反过来，A 也有硬伤：R07 的 A 篇把爽文改得更像散文（judgeR3 明确指出）。

**结论**：skill 提高了"想写好"的倾向，但没有提高"守住边界"的能力。**这两件事不是一回事，而且前者会侵蚀后者。** 这是本版最需要承认的设计缺陷。

### 2.3 篇幅这次控住了（14/14）

第一轮 B 组平均比 A 组长 7.6%，是明确的混杂因素。这一轮在任务书里写死区间（"必须落在区间内，超出算不合格"），并在 B 组的 prompt 里指回 SKILL.md 第 0 节的优先级第 1 条。

结果：14/14 全部合规，B 平均 1010 字、A 977 字（+3.4%），混杂大幅减小。

**但要看清归因**：这主要是"任务书写死了 + 明确点名优先级"的功劳，不完全是 skill 本身。skill 里的优先级条款起了作用，但它需要被显式提醒。

### 2.4 表层指标不可靠（第二轮与第一轮方向相反）

| 指标 | 第一轮 A→B | 第二轮 A→B |
|---|---|---|
| 情绪命名/千字 | 0.43 → 0.25（**下降**） | 0.27 → 0.39（**上升**） |
| 句长 CV | 0.59 → 0.67（上升） | 0.62 → 0.65（微升） |
| 对话占比 | 17.7% → 16.8% | 6.2% → 8.6% |

同一个指标在两轮里方向相反。**这说明这些数字不能当作"skill 有效"的证据**，只能当作描述。

另外一个排版层面的发现：**14/14 篇全部使用英文直引号（"…"），没有一篇用中文引号。** 两个组都一样，属于模型输出的通病，skill 没有纠正它，也没有要求纠正。v0.1.2 给 `craft_lint.py` 加了 `RAW_QUOTE` 提示，并把半角引号纳入对话统计（否则会把有对话的文本误判为"零对话"）。

## 3. 三章连续写作（探索性，单独报告，不并入统计）

任务：同一设定、同一情节骨架，写三章（每章 800–1000 字），考察人物设定一致性、因果衔接、章节衔接、重复套路。

结果：**2 位评审 1–1，无法判定。**

更要紧的是：**两位评审在"谁重复"这件事上互相矛盾**——judge1 说 B 重复"照信"和"邮车"母题，judge2 说 A 重复。核对原文后：

| 核查项 | A | B |
|---|---|---|
| "对着光看信"动作 | 出现 2 次（日头／灯泡） | 出现 2 次（窗／灯泡） |
| "邮车"母题 | 2 次 | 1 次 |
| 时间线自相矛盾 | 未发现 | 有 1 处（"干了两年" vs "那年四月还在县局帮工"） |

**结论**：
1. 跨章重复**两边都有**，是模型连续写作的通病，不是 skill 单方面造成。
2. B 组多一处时间线不一致。
3. 三章模式**没有证据支持 skill 更好或更差**。这是当前的能力空白，不是可用结论。

## 4. 统计口径（三个数字不能混）

| 指标 | 本轮有没有 | 含义 |
|---|---|---|
| **模型相对偏好比例** | 有：B 16/21 = 76% | 模型评审在两篇之间更愿意保留哪一篇。**不是人类阅读数据。** |
| **硬约束通过率** | 有：篇幅 14/14 = 100%；润色必留事实 5/5 = 100% | 客观、可复算。但只覆盖"能写成规则"的那部分要求。 |
| **真实用户阅读意愿** | **没有** | 需要人类读者。本轮 0 个真人样本。 |

任何"提升 X%"的说法，只能引用前两项。**不能**把 76% 说成"读者更喜欢"。

## 5. 局限

1. 7 个场景 × 每臂 1 篇，单篇方差大。
2. 评审仍是同一模型家族，且都只看到文本，没有读者背景。
3. R05 的失败虽然复现，但样本只有 2 个场景。
4. 三章实验只有 1 对稿、2 位评审，不足以支撑任何结论。
5. v0.1.2 的两处新改动（喜剧结尾、越界自查）**没有重测**。
