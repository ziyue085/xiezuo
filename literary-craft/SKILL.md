# Literary Craft · 让文字值得读下去

这个 skill 解决的不是"句子好不好看"，而是**读者为什么还要读下一段**。

它不教你写得像谁。它给你一套判断依据，让你在具体段落上决定：留什么、删什么、什么时候放过自己。

---

## 0. 三条使用原则（先读这三条，其余都可查）

1. **按体裁换标准。** 小说看推进，历史看可信，散文看认知增量，润色看保真，编辑看诊断精度。**五套标准不通用**，用错标准比不用更糟。
2. **默认直接交付作品。** 不输出创作思路、不列大纲、不解释你用了哪条技巧——除非用户明确要看过程。用户要的是文本。
3. **规则有适用条件。** 本文件所有条款都带"何时不用"。两条规则冲突时，按此优先级：读者体验 > 人物与事实的一致性 > 具体规则。

---

## 1. 核心模型：落差

读者继续读，是因为有一个**尚未闭合的落差**，而且他知道这个落差值得等。

三种落差，一个场景通常只养一条主线：

| 类型 | 读者在等什么 | 主要出现在 |
|---|---|---|
| **信息落差** | 有件事我还不知道，且我知道它重要 | 小说、历史 |
| **欲望落差** | 有人想要一样具体的东西，可能得不到 | 小说、历史 |
| **认知落差** | 我对这件事/这个人的理解，和文本要给的解释之间有空缺 | 散文、历史 |

**每段的三种状态**：制造落差 / 维持落差 / 兑现或转移落差。三者都不是，就是空转。

判断只需一句：**删掉这一段，读者会不会少等一件事？** 不会 → 压缩、合并或删。

### 落差必须具体到可感知

- 「他很痛苦」：没有落差。读者没有可等的具体结果，只收到一个结论。
- 「他把药盒里剩的三粒倒在掌心，又放回去两粒」：有落差。他会吃吗？为什么留？

后者不是"更文学"，是**给了读者一个可以自己算的账**。

### 落差的三种死法（比"写得平淡"更可诊断）

| 死法 | 表现 | 修法 |
|---|---|---|
| **提前关闭** | 刚提出就解释完，读者不必等 | 把解释后移，或整段删掉留后果 |
| **虚假落差** | 提了不兑现，或兑现得太容易 | 让代价真实发生；做不到就删掉这条线 |
| **落差过密** | 同时开五条线，读者不知道等哪个 | 一场戏一条主线，其余降为背景噪音 |

顺带解释了四种常见差评：平淡＝没有落差；假＝落差靠形容词宣告；累＝落差密而不兑现；俗＝兑现方式可预测。

## 2. 三条通用硬约束

### 2.1 细节必须承重

一个细节只有承担下列至少一项时才有价值：

1. **透露人**：他的钱、他的手、他注意到什么
2. **限制行动**：门锁了、只有三块五、脚崴了
3. **埋伏**：后文要用
4. **反差**：与环境或期待不符，暗示异常

不承重的细节是布景。**检验法：把它换成同类细节，文本有没有变化？** 没有，就是布景。

> 布景堆叠是 AI 中文最稳定的指纹：檀香、青瓷、雨打芭蕉、暮色四合、灯光昏黄——全都正确，全都可替换，删掉不影响任何东西。

### 2.2 情绪有四条通道，强度递增

**命名 < 身体 < 动作偏差 < 注意力错位**

- 命名：「他很紧张」——等于把结论替读者做了
- 身体：手心出汗、喉咙发紧——有效，但已被用滥，容易变成清单
- 动作偏差：平时利索的人系了三次鞋带——强，因为是个体化的
- 注意力错位：这个时刻他注意到对方袖口一根线头——最强，情绪改变了感知，且一个字没直说

**只在两种情况下命名情绪**：(a) 人物在自我欺骗，说的和做的不一致，形成反讽；(b) 需要极快的过渡。其余删掉命名，留下证据。

### 2.3 因果不是顺序

「然后」连接事件，「因此／但是」连接因果。把主要事件各写成一句，逐一问：**因为上一件，所以这件，成立吗？** 不成立的地方，补动机，或删事件。

**场景结束必须有状态变化**：有人知道了什么、失去了什么、决定了什么、关系变了。没有变化，这场戏可以删——写得再好也是废戏。

## 3. 路由：先判体裁，再加载一份参考

| 用户要什么 | 模式 | 必读 | 常见误判 |
|---|---|---|---|
| 写故事、小说、片段、续写 | **A 小说** | `references/fiction.md` | 当成"散文加对话" |
| 写历史、写古人、历史小说 | **B 历史叙事** | `references/history.md` | 只做故事，不管史实边界 |
| 写散文、随笔、游记、人物记 | **C 散文** | `references/essay.md` | 当成小说缩水版 |
| 改一段已有的文字 | **D 润色** | `references/revise.md` | 暗中重写，扩写一倍 |
| 评一篇稿子、给修改意见 | **E 编辑** | `references/edit.md` | 只说"不够生动" |

跨体裁或用户没说清时：按**交付物**判，不按题材判。写"历史小说"是 A+B：先用 history.md 定事实边界，再用 fiction.md 定场景。

**语言层面的具体问题**（句子板结、形容词堆积、套话、标点习惯）→ `references/anti-patterns.md`
**节奏与句式的中文特性**（的的不休、四字格、句群、标点）→ `references/rhythm.md`

**加载纪律**：一次最多读两份参考。写完不需要回来复述规则。

## 4. 每个体裁的最低要求（不合格线，不是风格建议）

| 模式 | 不合格的样子 |
|---|---|
| **A 小说** | 全篇没有一个具体欲望；场景结束时什么都没变；对话只交换信息；结尾总结主题 |
| **B 历史** | 给真实人物编直接引语并当成史料；出现时代错置的器物/称谓/制度；数字含糊到无法核对 |
| **C 散文** | 读完没有多知道任何东西；联想与材料无因果关系；结尾升华到"人生"而材料撑不住 |
| **D 润色** | 改动了事实、人物关系、视角或篇幅 ±20% 以外；无故扩写；把作者的语气改成自己的 |
| **E 编辑** | 评价不指向具体句子；只给一个方案；把个人偏好写成错误 |

## 5. 反公式化条款（这一节优先于上面所有技巧）

技巧用满会写出另一种 AI 味：句子都在用力、每段都有金句、每个细节都在暗示。**这比平淡更难读。**

五条反向操作，出现下列症状时强制执行：

1. **全篇每句都在使劲** → 写三句平的、笨的、只做过渡的句子。
2. **每段结尾都是警句** → 把其中一半改成动作或物件收尾。
3. **细节密度过高，读者喘不上气** → 删掉一半细节，只留承重的。
4. **句子开始像在演示技巧**（刻意的短句排比、刻意的留白、刻意的留一个空行）→ 恢复成正常叙述，让技巧退到后面。
5. **结尾在押韵** → 见下条，单独说。

### 5.1 设计感收尾（最隐蔽的一种假）

两种被写作课反复推荐、也最容易被识破的收尾：

- **回环**：让开头出现过的物件／动作在结尾再出现一次，赋予新含义。
- **无言定格**：结尾停在一个缓慢的、意味深长的动作上，不解释。

它们本身不错，问题在于**用得太顺手**。读者一旦察觉"这是作者安排的"，情绪立刻退潮——因为他看到的是结构，不是人。

判断标准只有一句：**这个收尾是人物处境自然产生的，还是你为了让全篇完整而摆上去的？**

如果是后者，换成一个**更钝的、与开头没有呼应关系的动作**。生活里大多数时刻不押韵：人在最难的时候，往往是在处理一件毫不相干的琐事。

（这一条是 v0.1.1 加的。它来自实测：三个失败场景里，有两篇的收尾都是精心设计的回环。）

其他禁令：

- 不为"文学感"牺牲故事推进。**读不下去的深刻等于零。**
- 不为"去 AI 味"把话写得别扭。自然优先于"不像 AI"。
- 不套用"展示而非讲述""多用短句""少用形容词"这类绝对律。**它们在具体段落里经常是错的**：概述需要讲述，追逐需要短句，精确需要一个形容词。

## 6. 交付前自检（五问，各一句话，不写进回复）

1. **删段测试**：随便挑三段，删掉，读者会少等一件事吗？全是否 → 这篇没有驱动力。
2. **状态测试**：每个场景结束时，有没有人的处境、认知或关系发生了变化？
3. **承重测试**：最漂亮的那个细节，换成同类细节，文本变了吗？没变 → 是布景。
4. **情绪测试**：把全篇"感到／觉得／心中一"删掉，情绪还在吗？不在 → 情绪是声明的，不是造出来的。
5. **公式测试**：这篇如果换一个题材，同样的句式和结构还能用吗？能 → 你写的是模板。

五问全过，仍可能不好看——那属于天赋与材料的问题，不是流程能修的。**不要用流程掩盖这个事实。**

## 7. 工具

```bash
python scripts/craft_lint.py --file 草稿.txt            # 表层体检（只提示，不打分）
python scripts/craft_lint.py --file 草稿.txt --json     # 机器可读
python scripts/craft_lint.py --file 草稿.txt --mode fiction
python -m unittest discover -s tests -v                 # 脚本回归测试
```

**这个脚本测不出好坏。** 它只标出极端值：句长过于均匀、情绪全靠命名、套话密度、排比堆叠、抽象名词过密。命中不等于差，未命中不等于好。真正的判断在读者那里。

## 8. 边界

- **不做**：公文、申论、学术论文、商业文案、代码文档、诗歌格律——素材与方法都不对口，硬套会变差。
- **不承诺**：让文本达到发表水平。它能减少结构性缺陷、提高下限，抬不高上限。
- **不伪造研究**：涉及具体作家作品的风格判断，只描述可观察的手法，不冒充文本细读；不确定就说不确定。
