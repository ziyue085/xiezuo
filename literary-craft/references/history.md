# B · 历史叙事：让过去可信，然后才好看

历史叙事的两个失败方向：**为了好看而编**，和**为了准确而无趣**。

这个文件处理第一个。第二个靠小说技法（fiction.md）解决。

---

## 1. 三层标注制度（本文件的核心）

任何历史叙事里的句子，只可能属于三类。混淆这三类，是历史写作最大的诚信问题。

| 层 | 定义 | 处理方式 |
|---|---|---|
| **史** | 有明确史料记载，可指向具体出处 | 可直接陈述；重要处标注来源类别 |
| **推** | 史料未载，但可由已知条件合理推断 | 用推断语气（"很可能""据此推测""按当时惯例"）；不写成事实 |
| **构** | 为叙事需要虚构的场景、对白、心理 | 必须让读者能分辨；不对真实人物编造直接引语 |

### 两种落地方式

**显式标注（推荐用于知识性、科普性历史写作）**

> 万历五年秋，张居正的父亲在江陵去世。〔史〕按制，官员须离职守孝二十七个月。〔史〕但他选择了"夺情"——由皇帝下诏免于守制。〔史〕朝中反对声浪之大，可能超出他的预估。〔推〕
>
> 以下这场夜谈，史无记载。〔构〕所据者，仅为当时双方立场与已知性格。

**内嵌标注（推荐用于叙事性历史写作，标注密度降低但必须保留）**

> 据《明史》本传，他此后三次上疏，都被留中不发。〔史〕
> 那天夜里他是否真的写完了第四封，无从得知。〔推〕他不像是会停手的人。

**判定规则**：读者读完之后，是否能指出"哪句是史料、哪句是推测、哪句是虚构"？不能，就是标注失败。

## 2. 五条硬禁令

1. **不给真实历史人物编造直接引语并当作史料。**
   可以写"他说了什么"，但要么用史料原意转述，要么明确写"以下对白为重构"。**引号在历史写作里是有法律责任的符号。**

2. **不编造史料出处。** 不写"《明实录》卷三百二十一载"，除非确有其事。宁可写"据《明史》相关列传"，也不要精确到卷次页码。**精确的假比模糊的真更可恶。**

3. **不给真实人物安排无据的私密心理。** 「他此刻想起母亲」——史书不会记这个。可以写"他后来在信中提及此事"，不能写"他当时心中一阵酸楚"。

4. **不把后世评价塞进当事人嘴里。** 让 16 世纪的人用 21 世纪的"制度""体制""系统性"思考，是时代错置，也是最常见的假深刻。

5. **不为了戏剧性改变关键事实的因果。** 可以压缩时间、合并场景、虚构次要人物；不能让人物在错误的时间出现在错误的地点，不能改变胜负、生死、诏令内容。

## 3. 时代校验清单（写古代题材必过）

逐项检查，任何一项出错，读者里的行家会立刻不信。

| 项 | 常见错误 |
|---|---|
| **称谓** | 明清平民称官员"大人"（多为戏曲影响）；宋代称"相公"；"爹娘"vs"父母"vs"老爷太太" |
| **官制** | 巡抚/总督的设置在明代非固定；知县与知府权限混淆 |
| **货币物价** | 明代白银与铜钱并行，一两银 ≈ 多少文随年景剧烈波动；不要写"一两银子买碗面" |
| **度量** | 一里≈576 米（清制）；一斤十六两；石、斗、升的换算 |
| **饮食器物** | 辣椒明代后期才传入；番薯、玉米的推广在清；玻璃器昂贵；棉布在明代才普及 |
| **信息速度** | 驿站日行 300 里为急件；京城到江南约 10–15 天；边报更慢 |
| **交通** | 步行日 30–40 里；船运受季风与运河闸口限制 |
| **历法与时间** | 农历日期、时辰；"几点钟"是近代说法 |
| **避讳** | 清代避"玄烨"，明代避皇帝名；写错会显得完全没做功课 |

**不确定时的正确做法**：把精确换成功能。不写"他花了三两七钱银子"，写"他掏空了钱袋，还差一截"。**功能性的准确优于数字的虚假精确。**

## 4. 张力从哪来：后见之明做结构，当事人视角做场景

历史叙事有一个小说没有的优势：**读者知道结局，人物不知道。**

这就是天然的戏剧反讽。

- **结构层**：你可以用后见之明安排章节（这个人正在走向他知道的结局）。
- **场景层**：必须切回当事人的信息边界——他只知道当时能知道的事，他的判断按当时的逻辑是合理的。

**最有力的写法**：让读者看着一个聪明人，用完全正确的推理，走向一个错误的结果。

> 他算得很准：粮价、兵力、朝廷的犹豫，全在预期之内。他唯一没算到的是，皇帝会比他的信使早三天知道消息。
>
> ——这一句"没算到"，比任何抒情都有力量。

**禁止**："如果他能预见到……"（廉价的感慨）、"历史将证明……"（作者跳出场景）。

---

## 5. 具体性：历史叙事的可信度来自规模感

空泛的历史叙述永远像旅游宣传片。**给出可以换算的数字，读者才会相信。**

三种可用材料：

1. **价格与收入**：一石米多少钱，一个衙役月俸多少，一场宴席花费几何
2. **时间与距离**：走多久、等几天、信什么时候到
3. **数量与比例**：多少人、占几成、死了几个

> 弱：大军压境，城中人心惶惶。
> 强：围城的第四十一天，城里开始按户配米，一户一日三合。有人在城墙上往下看，看见敌营的灶比昨天多了一倍。

**数字纪律**：能查到的写准确值并标注来源；查不到的写区间或写"约"；完全不知道的，**写功能不写数字**。

## 6. 史料冲突怎么办

史料互相矛盾是常态，不是障碍。

三种正确处理：

1. **并列两说**："《甲》记为三千，《乙》记为八千，相差悬殊，真实数目已不可考。"
2. **说明取舍**："本文采《甲》说，因《乙》成书较晚，且作者有为其乡人回护之意。"
3. **停在不确定**："两种记载都无法证伪。这个数字本身，可能比事件更适合说明当时的信息状况。"

**错误做法**：取一个对自己叙事最方便的，然后不提另一种。这不是剪裁，是篡改。

## 7. 历史小说的接口（A+B 同时用）

| 层次 | 规则 |
|---|---|
| **骨架** | 大事年表、地理、制度、人物关系，必须真 |
| **血肉** | 次要人物、日常细节、对白，可虚构 |
| **红线** | 真实人物的重大言行、生死、立场，不可改 |
| **标注** | 正文可内嵌轻标注；文末加一段"史实与虚构说明"，列出哪些是编的 |

**读者契约**：历史小说允许虚构，但不允许**让读者误以为虚构是史实**。文末说明不是免责声明，是对读者的基本尊重。

---

## 8. 自查（历史专用）

1. 随便挑三句陈述，能说清哪句是史、哪句是推、哪句是构吗？
2. 全篇有没有给真实人物编的直接引语？如果有，标注了吗？
3. 有没有出现精确到卷次的出处？能核实吗？
4. 时代校验清单九项，过了几项？没过的那几项，是不是恰好被读者最可能注意到？
5. 场景里的当事人，用的是当时的信息和当时的逻辑，还是作者的全知视角？
6. 数字里，哪些是可核的，哪些是估的？估的有没有用"约"或写功能？

**第 2、3 条任一不合格，这篇不能交付。** 其余的可以带着缺陷交付，但要在这篇的说明里写清楚。
