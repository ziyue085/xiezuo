# D · 润色：只改需要改的地方

润色最容易犯的错不是改坏，是**改多了**。

用户给你一段文字，是让你修，不是让你替他重写。**重写等于取消了他的作者身份。**

---

## 1. 先分级，再动手（默认只做 L1）

| 级别 | 范围 | 是否需用户同意 |
|---|---|---|
| **L0 校订** | 错别字、标点、病句、事实性错误、前后矛盾 | 不需要，直接改 |
| **L1 局部改写** | 句子和段落层面的表达问题（默认档位） | 不需要 |
| **L2 结构改写** | 调整顺序、增删场景、改变叙述视角、改变结尾 | **必须先说明并获得同意** |

用户说"润色""改改"→ L1。
用户说"随便改""改成能读的"→ 可做 L2，但仍要先说明改哪里。
用户说"只改错字"→ L0，看到其他问题**只提，不动**。

---

## 2. 先抄一份事实清单（不抄不许改）

润色的第一步不是改句子，是把原稿的事实抄出来。抄在纸上，或者单独放在回复之外——不放进给用户的正文。

| 栏 | 抄什么 |
|---|---|
| **人物** | 每个名字、称谓、彼此关系（谁是谁的弟弟） |
| **时间** | 年、月、日、季节、先后顺序 |
| **数字** | 金额、数量、比例、年龄、里程，连同单位 |
| **事件** | 一行一件，按原顺序（"赵德海把苹果拉进冷库"） |
| **因果** | 明写或暗示的"因为A所以B"，标出来 |
| **未说明** | 原稿没交代的（他为什么借这笔钱）——**不要替他补** |
| **形式** | 人称、视角、文体、篇幅 |

改完，逐条对：

- **少一条** → 事实损失，补回来。
- **改一条** → 未经授权的篡改，改回去。
- **多一条** → 你新增了事实，**删掉**。

**只有三类新增是允许的**：连接词、必要的指代（"他"）、为通顺服务的虚词。其余一律算越界。

**未经用户明确授权，不得新增**：事件、人物、背景交代、数字、时间点、下一场的钩子、续写暗示。哪怕它让文章更好看——那不叫润色，叫代写。

（v0.1.3 加。起因：R07 的润色稿补写了离职细节、埋了下一场的钩子，评审判"是改写并且换了文体"。该用例保留为回归测试。）

## 3. 最小改动原则

三条操作顺序，从上到下：

1. **能删则删**：多余的解释、重复的情绪、无信息的形容词——删掉比改写更安全
2. **能改一句不改一段**：只动有问题的那个句子，周围不动
3. **能不加就不加**：新增内容是最容易越界的操作，除非原文缺了关键因果

**判断某个地方要不要动，问一句**：不动它，读者会不会看不懂或者出戏？不会 → 不动。

### 3.1 越界自查（改完做一遍）

- 数一数**新增**的句子。新增超过原文一成半，或者新增了原文没有的情节、人物、背景交代——退回重做。
- 如果新增的是"为了让转折更顺"的过渡段，问：原文真的缺这段，还是我想让它更好看？
- 润色不是把文章改得更好，是**把它改成它自己最好的样子**。这两者的差别，全在"加了多少"。

## 4. 六类高频问题与最小修法

### 4.1 情绪靠命名

> 原：她感到一阵莫名的悲伤，眼泪不由自主地流了下来。
> 改：她低头去系鞋带，系了两次都没系上。

**修法**：删掉"感到／莫名／不由自主"，换一个具体的动作偏差。**只改这一句，前后不动。**

### 4.2 形容词堆积

> 原：破旧的、低矮的、灰扑扑的老屋静静地立在昏黄的暮色中，显得格外凄凉。
> 改：老屋的墙皮掉了一半，露出里面的土坯。

**修法**：四个形容词里选**最不准的那个删掉**，剩下的换成一个可观察的事实。不要全换成比喻。

### 4.3 过度解释

> 原：他把碗放下，站起身走了。这个动作说明他已经下定决心，不再回头。
> 改：他把碗放下，站起身走了。

**修法**：删掉解释句，只留后果。**这是最安全、收益最高的一类修改。** 拿不准时先删掉读一遍——如果读起来没有损失，就不用加回来。

### 4.4 对话没有潜台词

> 原：「我很担心你。」他说。「我知道，」她说，「但这是我自己的选择。」
> 改：「几点的车。」他说。「九点。」「东西都带了？」「带了。」

**修法**：把一句直抒胸臆改成一句**答非所问**或**具体事务**。不要整段重写。

### 4.5 节奏板结

> 原：他走进房间，看见桌上放着一封信，他拿起信，拆开信封，取出信纸，开始阅读。
> 改：桌上有封信。他拆开，看了两行，坐下了。

**修法**：把连续同构的短句合并，或把一句拆成两句制造停顿。**只动这一处，不全文重排。**

### 4.6 假细节

> 原：墙上挂着一幅山水画。
> 改：墙上挂着一幅印刷的山水，右下角还留着"XX 宾馆赠"的字。

**修法**：给细节加一个**可核的来源或瑕疵**。加了之后要问：这个细节后文用得上吗？用不上就删掉整句，别加。

## 5. 输出格式

三段，不要更多：

```
【改后全文】
（完整文本，不加标注、不加高亮）

【改了什么】
1. 第 3 段「她感到一阵莫名的悲伤」→ 换成系鞋带的动作。原因：情绪被命名，读者无参与空间。
2. 删掉第 7 段末的解释句。原因：结论已由前文动作给出，解释反而削弱。
...

【需要你决定】
- 第 5 段的年代线索与第 2 段冲突（1998 vs 2003），我按 1998 改了。如果原意是 2003，请告知。
```

**不要**在正文里插入 `[修改]`、`（原：…）`、删除线。用户要的是一份能直接用的文本。

---

## 6. 禁忌

1. **无故扩写。** 把 800 字改成 1600 字，即使更好读，也是违约。
2. **改人物设定。** 原来懦弱的人不能变得果断；原来没读过书的人不能突然用成语。
3. **改视角。** 第一人称改第三人称是重写，不是润色。
4. **加金句。** 在段末加一句"原来……"式总结，是把自己的趣味盖在作者身上。
5. **改事实以迁就文笔。** 数字不好看就改数字，是最严重的越界。
6. **把方言、口语、错误语法一律规范化。** 有些"不规范"是声音，删了就没了。**判断标准：这是作者的语感，还是他没写对？** 拿不准就问。

---

## 7. 与"编辑"的区别

| | 润色 | 编辑 |
|---|---|---|
| 交付物 | 改好的文本 | 诊断报告 + 修改建议 |
| 动不动原文 | 动 | 原则上不动（除示范句） |
| 用户要什么 | "帮我改好" | "告诉我哪里不好" |

用户要"看看哪里有问题"，不要直接给改好的全文——那是越权。**先诊断，问他要不要改。**
